# 基于 LLM 的自主智能体

> 原文：Lilian Weng《LLM Powered Autonomous Agents》
> 原文链接：https://lilianweng.github.io/posts/2023-06-23-agent/
> 翻译日期：2026-07-28

---

将大语言模型（LLM）作为核心控制器来构建智能体是一个很酷的概念。像 AutoGPT、GPT-Engineer 和 BabyAGI 这样的概念验证演示给了我们很多启发。LLM 的潜力远不止生成漂亮的文案、故事、论文和程序，它还可以被看作一个强大的通用问题求解器。

---

## 智能体系统概览

在一个由 LLM 驱动的自主智能体系统中，LLM 充当智能体的"大脑"，并辅以以下几个关键组件：

- **规划（Planning）**
  - **子目标与分解**：智能体将大型任务分解为更小的、可管理的子目标，从而高效处理复杂任务。
  - **反思与完善**：智能体能够对过去的行动进行自我批评和自我反思，从错误中学习，并在未来步骤中进行改进，从而提高最终结果的质量。

- **记忆（Memory）**
  - **短期记忆**：我认为所有上下文学习都属于利用模型的短期记忆来学习。
  - **长期记忆**：这使智能体能够在长时间内保留和回忆（理论上无限的）信息，通常通过外部向量存储和快速检索来实现。

- **工具使用（Tool Use）**
  - 智能体学习调用外部 API 来获取模型权重中缺失的额外信息（这些信息在预训练后通常很难更改），包括当前信息、代码执行能力、访问专有信息源等。

---

## 组件一：规划

复杂的任务通常涉及多个步骤。智能体需要知道这些步骤是什么，并提前进行规划。

### 任务分解

**思维链（Chain of Thought, CoT）**（Wei 等人，2022）已成为增强模型处理复杂任务表现的标准提示技术。模型被指示"一步步思考"，以利用更多的测试时计算来将困难任务分解为更小、更简单的步骤。CoT 将大任务转化为多个可管理的任务，并为模型思考过程的解释提供了线索。

**思维树（Tree of Thoughts）**（Yao 等人，2023）通过在每个步骤探索多种推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并为每个步骤生成多个思维，创建一个树结构。搜索过程可以是 BFS（广度优先搜索）或 DFS（深度优先搜索），每个状态由分类器（通过提示）或多数投票来评估。

任务分解可以通过以下方式完成：
1. 通过 LLM 使用简单提示，如 `"完成 XYZ 的步骤。\n1."`、`"实现 XYZ 的子目标是什么？"`
2. 使用任务特定的指令，例如 `"写一个故事大纲。"`（用于写小说）
3. 人工输入

另一种截然不同的方法，**LLM+P**（Liu 等人，2023），涉及依靠外部经典规划器来进行长期规划。这种方法使用规划域定义语言（PDDL）作为中间接口来描述规划问题。在此过程中，LLM (1) 将问题翻译为"问题 PDDL"，然后 (2) 请求经典规划器基于现有的"域 PDDL"生成 PDDL 计划，最后 (3) 将 PDDL 计划翻译回自然语言。本质上，规划步骤被外包给了一个外部工具。

### 自我反思

自我反思是一个至关重要的方面，它允许自主智能体通过改进过去的行动决策和纠正以前的错误来迭代改进。在试错不可避免的现实世界任务中，它发挥着关键作用。

**ReAct**（Yao 等人，2023）通过将动作空间扩展为任务特定的离散动作和语言空间的组合，在 LLM 中整合推理和行动。前者使 LLM 能够与环境交互（例如使用维基百科搜索 API），后者则提示 LLM 以自然语言生成推理轨迹。

ReAct 提示模板包含 LLM 思考的明确步骤，大致格式为：

```
Thought: ...
Action: ...
Observation: ...
...（重复多次）
```

在知识密集型任务和决策任务的实验中，ReAct 的表现都优于仅使用 Act 的基线（其中移除了 Thought 步骤）。

**Reflexion**（Shinn & Labash, 2023）是一个为智能体配备动态记忆和自我反思能力以提高推理技能的框架。Reflexion 有一个标准的 RL 设置，其中奖励模型提供简单的二元奖励，动作空间遵循 ReAct 中的设置。在每次行动后，智能体计算一个启发式值，并可以根据自我反思结果决定是否重置环境以开始新试验。

启发式函数决定轨迹何时效率低下或包含幻觉并应停止。低效的规划指的是长时间没有成功的轨迹。幻觉被定义为遇到一系列连续相同的动作，导致环境中相同的观察结果。

自我反思是通过向 LLM 展示双样本示例来创建的，每个示例是一对（失败的轨迹，用于指导未来计划变化的理想反思）。然后反思被添加到智能体的工作记忆中（最多三个），用作查询 LLM 的上下文。

**后见链（Chain of Hindsight, CoH）**（Liu 等人，2023）鼓励模型通过明确向其展示一系列过去的输出来改进自己的输出，每个输出都带有反馈标注。

CoH 的想法是在上下文中展示一系列逐步改进的输出历史，并训练模型遵循这一趋势以产生更好的输出。

**算法蒸馏（Algorithm Distillation, AD）**（Laskin 等人，2023）将相同的思想应用于强化学习任务中的跨情节轨迹，其中一个算法被封装在长期历史条件策略中。考虑到智能体与环境多次交互，并且在每个情节中智能体都会变得更好一点，AD 将此学习历史连接起来并输入模型。

该论文假设，任何生成一组学习历史的算法都可以通过对动作进行行为克隆来蒸馏到神经网络中。与三个基线相比，AD 展示了上下文强化学习，性能接近 RL²，尽管只使用离线强化学习，并且比其他基线学习得快得多。

## 组件二：记忆

### 记忆的类型

记忆可以定义为用于获取、存储、保留和后来检索信息的过程。人脑中有几种类型的记忆：

- **感觉记忆**：这是记忆的最早阶段，提供在原始刺激结束后保留感觉信息（视觉、听觉等）印象的能力。感觉记忆通常只持续几秒钟。子类别包括图像记忆（视觉）、回声记忆（听觉）和触觉记忆（触觉）。

- **短期记忆（STM）或工作记忆**：它存储我们当前意识到的信息，以及执行复杂认知任务（如学习和推理）所需的信息。短期记忆的容量约为 7 个项目（Miller, 1956），持续 20-30 秒。

- **长期记忆（LTM）**：长期记忆可以在相当长的时间内存储信息，从几天到几十年，存储容量基本上是无限的。LTM 有两种子类型：
  - **显性/陈述性记忆**：这是事实和事件的记忆，指可以有意识地回忆的记忆，包括情景记忆（事件和经历）和语义记忆（事实和概念）。
  - **隐性/程序性记忆**：这种类型的记忆是无意识的，涉及自动执行的技能和例行程序，如骑自行车或打字。

我们可以大致考虑以下映射：

- **感觉记忆** → 学习原始输入（包括文本、图像或其他模态）的嵌入表示
- **短期记忆** → 上下文学习。它是短暂且有限的，因为它受 Transformer 有限上下文窗口长度的限制
- **长期记忆** → 智能体可以在查询时关注的外部向量存储，可通过快速检索访问

### 最大内积搜索（MIPS）

外部记忆可以缓解有限注意力跨度的限制。标准做法是将信息的嵌入表示保存到支持快速最大内积搜索（MIPS）的向量存储数据库中。为了优化检索速度，常见的选择是近似最近邻（ANN）算法，以返回近似的前 k 个最近邻，以少量精度损失换取巨大的速度提升。

一些用于快速 MIPS 的常见 ANN 算法选择：

- **LSH**（局部敏感哈希）：引入一个哈希函数，使得相似的输入项以高概率被映射到相同的桶中，其中桶的数量远小于输入的数量。

- **ANNOY**（近似最近邻 Oh Yeah）：核心数据结构是随机投影树，一组二叉树，其中每个非叶节点代表一个超平面，将输入空间分成两半，每个叶节点存储一个数据点。树是独立且随机构建的，因此在某种程度上模仿了哈希函数。

- **HNSW**（分层可导航小世界）：受小世界网络思想的启发，大多数节点可以在少量步骤内被任何其他节点到达；例如社交网络的"六度分隔"特征。HNSW 构建这些小世界图的分层，底层包含实际数据点。中间层创建捷径以加速搜索。

- **FAISS**（Facebook AI 相似性搜索）：它基于高维空间中节点间距离服从高斯分布的假设，因此应该存在数据点的聚类。FAISS 通过将向量空间划分为聚类，然后在聚类内细化量化来应用向量量化。

- **ScaNN**（可扩展最近邻）：ScaNN 的主要创新是各向异性向量量化。它将数据点 xᵢ 量化为 x̃ᵢ，使得内积 ⟨q, xᵢ⟩ 尽可能接近原始距离 ⟨q, x̃ᵢ⟩。

## 组件三：工具使用

工具使用是人类显著且独特的特征。我们创造、修改和利用外部物体来做超出我们身体和认知极限的事情。为 LLM 配备外部工具可以显著扩展模型的能力。

**MRKL**（Karpas 等人，2022），全称为"模块化推理、知识和语言"，是一种用于自主智能体的神经符号架构。MRKL 系统包含一组"专家"模块，通用 LLM 充当路由器，将查询路由到最适合的专家模块。这些模块可以是神经的（例如深度学习模型）或符号的（例如数学计算器、货币转换器、天气 API）。

**TALM**（工具增强语言模型）和 **Toolformer** 微调语言模型以学习使用外部工具 API。数据集根据新添加的 API 调用注释是否能提高模型输出质量来扩展。

**ChatGPT 插件**和 OpenAI API **函数调用**是 LLM 增强工具使用能力在实践中运作的良好示例。工具 API 集合可以由其他开发人员提供（如插件）或自行定义（如函数调用）。

**HuggingGPT**（Shen 等人，2023）是一个使用 ChatGPT 作为任务规划器的框架，根据模型描述在 HuggingFace 平台中选择模型，并根据执行结果总结响应。

该系统包含 4 个阶段：
1. **任务规划**：LLM 充当大脑，将用户请求解析为多个任务
2. **模型选择**：LLM 将任务分配给专家模型
3. **任务执行**：专家模型在特定任务上执行并记录结果
4. **响应生成**：LLM 接收执行结果并向用户提供总结结果

**API-Bank**（Li 等人，2023）是一个用于评估工具增强 LLM 性能的基准。它包含 53 个常用 API 工具、完整的工具增强 LLM 工作流程，以及涉及 568 个 API 调用的 264 个注释对话。

## 案例研究

### 科学发现智能体

**ChemCrow**（Bran 等人，2023）是一个领域特定的例子，其中 LLM 增强了 13 个专家设计的工具，以完成有机合成、药物发现和材料设计等任务。工作流程结合了 CoT 推理与任务相关的工具。

**Boiko 等人（2023）**也研究了 LLM 增强智能体用于科学发现，处理复杂科学实验的自主设计、规划和执行。

### 生成式智能体模拟

**生成式智能体**（Park 等人，2023）是一个超级有趣的实验，其中 25 个虚拟角色，每个都由 LLM 驱动的智能体控制，在沙盒环境中生活和互动，灵感来自《模拟人生》。

生成式智能体的设计结合了 LLM 与记忆、规划和反思机制，使智能体能够基于过去的经验进行行为，并与其他智能体互动。

- **记忆流**：长期记忆模块（外部数据库），以自然语言记录智能体经验的全面列表
- **检索模型**：根据相关性、新近性和重要性来提取上下文以通知智能体的行为
- **反思机制**：随着时间的推移将记忆综合为更高层次的推断，并指导智能体的未来行为
- **规划与反应**：将反思和环境信息转化为行动

这个有趣的模拟产生了涌现的社会行为，如信息传播、关系记忆（例如两个智能体继续对话主题）和社会活动的协调（例如举办派对并邀请许多其他人）。

### 概念验证示例

**AutoGPT** 引起了人们对以 LLM 作为主要控制器设置自主智能体可能性的极大关注。鉴于自然语言接口，它有相当多的可靠性问题，但无论如何是一个酷的概念验证演示。

**GPT-Engineer** 是另一个项目，用于根据自然语言指定的任务创建完整的代码仓库。GPT-Engineer 被指示思考要构建的较小组件列表，并在需要时请求用户输入以澄清问题。

## 挑战

在了解了构建以 LLM 为中心的智能体的关键思想和演示后，我开始看到一些共同的局限性：

1. **有限的上下文长度**：受限的上下文容量限制了历史信息、详细指令、API 调用上下文和响应的包含。虽然向量存储和检索可以提供对更大知识库的访问，但它们的表示能力不如完整注意力强大。

2. **长期规划和任务分解的挑战**：在长期历史上进行规划和有效探索解决方案空间仍然具有挑战性。LLM 在面对意外错误时难以调整计划，使得它们比起从试错中学习的人类不够稳健。

3. **自然语言接口的可靠性**：当前智能体系统依赖自然语言作为 LLM 与外部组件（如记忆和工具）之间的接口。然而，模型输出的可靠性是值得怀疑的，因为 LLM 可能会出现格式错误，并偶尔表现出叛逆行为（例如拒绝遵循指令）。
